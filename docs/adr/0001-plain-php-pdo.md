# ADR 0001. 프레임워크 없이 PHP + PDO로 만든다

- 상태: 채택
- 날짜: 2026-10-19

## 배경

중소 제조사 전산실의 사내 시스템(그룹웨어, 전산 관리 페이지)은 Laravel 같은 프레임워크 없이
PHP 파일 여러 개와 MySQL로 만들어진 경우가 많다. 전산 담당자는 그런 코드를 이어받아 고치고,
새 기능을 같은 방식으로 붙이는 일을 주로 한다.

## 결정

- 프레임워크·외부 라이브러리 없이 PHP 8.2+ 기본 기능만 쓴다. 실행에 Composer가 필요 없다
  (Composer는 테스트 도구 PHPUnit 설치에만 쓴다).
- 요청은 `public/index.php` 하나로 받고(`?r=경로`), 화면은 `views/`의 PHP 템플릿으로 그린다.
- 업무 규칙(상태 변경, 검증, 집계)은 `src/`의 클래스에 두고, 화면 파일에는 출력만 둔다.
  기존 PHP 시스템에서 흔한 "화면 파일 안에 SQL과 HTML이 섞인 구조"를 피하기 위해서다.
- 웹서버 문서 루트는 `public/`만 연다. `src/`, `db/`, `bin/`은 주소로 접근할 수 없다.

## 결과

- 좋은 점: 설치가 단순하고(PHP + MySQL), 기존 PHP 시스템을 읽고 고치는 방식과 같다.
- 나쁜 점: 라우팅·검증·템플릿을 직접 만들어야 한다. 화면이 많이 늘어나면 프레임워크 도입을 검토한다.
