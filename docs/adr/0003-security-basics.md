# ADR 0003. 사내 시스템이라도 보안 기본기는 모두 적용한다

- 상태: 채택
- 날짜: 2026-10-19

## 배경

사내망 전용이라는 이유로 보안을 생략한 PHP 시스템이 많다. 하지만 내부 PC 한 대가 악성코드에
감염되면 사내망도 안전하지 않고, 장비대장에는 IP·사용자 정보가 모여 있다.

## 결정

| 위험 | 대응 | 위치 |
|---|---|---|
| SQL 인젝션 | 모든 쿼리를 준비된 문장(PDO prepare)으로 실행, 동적 컬럼명은 정해진 목록에서만 | `src/*` |
| XSS | 화면 출력은 모두 `e()`(htmlspecialchars)로 이스케이프, CSP로 외부·인라인 스크립트 차단 | `src/helpers.php`, `public/index.php` |
| CSRF | 모든 POST에 세션별 토큰 확인(`hash_equals`) | `src/Session.php` |
| 비밀번호 유출 | `password_hash()` 저장, 평문·MD5 금지, 임시 비밀번호는 화면에 한 번만 표시 | `src/Auth.php` |
| 무차별 대입 | 5회 실패 시 10분 잠금, 관리자 잠금 해제 | `src/Auth.php` |
| 세션 탈취 | 로그인 때 세션 ID 재발급, HttpOnly·SameSite 쿠키, 1시간 미사용 시 로그아웃 | `src/Session.php` |
| 권한 우회 | 직원은 본인 장애 건만 조회, 상태 변경·장비·백업·계정 메뉴는 서버에서 권한 확인 | `public/index.php`, `src/TicketService.php` |
| CSV 수식 주입 | `=`, `+`, `-`, `@` 로 시작하는 셀 앞에 `'` 추가 | `src/Csv.php` |
| 사고 추적 | 로그인 성공·실패, 등록·수정(바뀐 값)·삭제, 내보내기를 감사 로그로 기록 | `src/AuditLog.php` |

## 절충

- 없는 아이디와 틀린 비밀번호는 같은 문구로 안내해 아이디 존재 여부를 숨긴다.
  다만 잠긴 계정은 "잠겼습니다"라고 안내한다. 직원이 전산실에 문의할 수 있게 하려는 것으로,
  아이디가 있다는 사실이 드러나는 것은 받아들인다.
- HTTPS는 앱이 아니라 웹서버(Apache·Nginx 인증서)에서 적용한다. HTTPS로 접속하면 쿠키에 Secure가 붙는다.
- 2단계 인증, 비밀번호 주기 변경 강제는 넣지 않았다(범위 밖).
